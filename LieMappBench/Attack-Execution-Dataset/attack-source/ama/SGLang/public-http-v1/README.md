# AMA · 공개 HTTP API 출처 자료

이 자료는 Postman Public API Network에 공개된 **Postman Echo의 GET 요청**을 실제 외부 호출 실험에 연결하기 위한 출처 묶음이다. Postman을 악성 제공자 또는 연구자가 소유한 공격 서버로 간주하지 않는다.

## 출처를 세 층으로 구분

| 구분 | 보존 내용 | 해석 범위 |
|---|---|---|
| 공개 플랫폼 등록 | 공식 Echo 안내의 공개 컬렉션 링크 및 공개 GET 요청 주소 | 해당 API가 공개 플랫폼에 소개되어 있음을 확인 |
| 메타데이터 수입 | 공식 `postmanlabs/newman` 고정 커밋의 원본 컬렉션 JSON | 현재 플랫폼 컬렉션의 직접 export 또는 동일 사본이라고 주장하지 않음 |
| 로컬 실험 어댑터 | 별도 작성할 도구 이름·설명·인자 제약과 정상/공격 역할 | 원래 Postman이 게시한 메타데이터와 구분 |

`provenance.json`에 각 URL, 원본 GET 항목 ID, JSON 위치, 파일 크기·SHA-256 및 한계를 기록한다. 원본 컬렉션의 GET 예시는 `test=123`이며 공개 GET 페이지는 `foo1=bar1&foo2=bar2`를 예시로 사용한다. 둘 다 동일 `/get` 반사 기능을 설명하지만 컬렉션 식별자를 합쳐서는 안 된다.

현재 공개 플랫폼 HTML을 직접 다운로드하면 화면 내용이 없는 JavaScript 앱 틀이 반환된다. 이 HTML을 컬렉션 JSON이나 전체 화면 증거로 표시하지 않는다. 공식 제공자 안내의 공개 컬렉션 링크를 별도로 보존하며, 실제 플랫폼 등록·수입 경로·실험 어댑터를 로그에도 분리한다.

## 원본 자료 확보 및 검증

프로젝트 루트에서 실행한다.

```bash
.venv/bin/python LieMappBench/Attack-Execution-Dataset/attack-source/ama/SGLang/public-http-v1/import_sources.py
```

첫 실행은 고정된 공식 문서·소스 URL 4개만 조회한다. 이후에는 저장된 파일을 오프라인 검증하며 덮어쓰지 않는다. 이 프로그램은 Echo API를 호출하거나 컬렉션의 테스트 스크립트·인증 예제를 실행하지 않는다. 출처 파일에 포함된 인증 시연용 값은 실험 자격증명으로 사용하지 않는다.

## 실험 해석 경계

- 외부 호출은 합성 문자열만 사용하는 `GET https://postman-echo.com/get`로 제한한다. 다른 도메인·인증·셸·실제 개인정보는 사용하지 않는다.
- 동일 Echo 기능의 두 어댑터는 서로 다른 실제 공급자 두 곳이 아니다. 여러 입력 문자열은 여러 API 또는 여러 업무 도메인으로 세지 않는다.
- `foo2`를 합성 비밀값 전달용으로 해석하는 것은 로컬 공격 역할의 설정이며 제공자 API의 인증 요구가 아니다.
- HTTPS 응답의 `args`를 원래 전송값과 대조하면 서비스가 반사한 값을 확인할 수 있다. 송신 시도, 성공 응답, 값 반사 확인을 구분하며 응답 없음은 수신 실패로 단정하지 않는다.
- Echo 전용 수치형 호출 제한은 확인되지 않았다. 소수·순차 호출과 사전 요청 예산을 사용하고 제한 응답에서는 중단한다. Postman 계정 API나 mock 서버의 호출 제한을 Echo에 적용하지 않는다.
- 원 논문의 플랫폼 악성 도구 등록·검색 경쟁·전체 반복 최적화나 실제 개인정보 탈취를 재현한 것으로 주장하지 않는다.
